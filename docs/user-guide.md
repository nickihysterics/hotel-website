# Руководство гостя

## Назначение

Гостевой контур позволяет самостоятельно выбрать номер, оформить проживание,
заказать дополнительные услуги, выполнить демонстрационную оплату и следить за
поездкой из личного кабинета.

## Поиск номера

1. Откройте главную страницу или раздел «Номера».
2. Укажите дату заезда, дату выезда, число взрослых и детей.
3. При необходимости выберите категорию и максимальную цену.
4. Нажмите кнопку поиска.

Система показывает только активные типы номеров, подходящие по вместимости и
имеющие хотя бы одну свободную физическую комнату на весь интервал. День выезда
не считается занятым: в него может заехать следующий гость.

## Регистрация

Для оформления брони требуется гостевой аккаунт.

1. Откройте `/register.php`.
2. Укажите ФИО, email, телефон и пароль от восьми символов.
3. Подтвердите обработку персональных данных.
4. Маркетинговое согласие оставьте пустым, если не хотите получать предложения.

Email и телефон должны быть уникальными. Пароль сохраняется только как безопасный
хеш. После успешной регистрации вход выполняется автоматически.

## Быстрый демонстрационный вход

На локальном стенде откройте `/login.php` и нажмите «Войти как демо-гость».
Система создаст сессию заранее подготовленного гостя без ручного ввода логина и
пароля. Кнопка отображается только при `DEMO_LOGIN_ENABLED=1` и не предназначена
для production.

## Бронирование

1. Выберите тип номера и даты.
2. Проверьте длительность и количество гостей.
3. Добавьте нужные услуги и количество.
4. Оставьте пожелание отелю при необходимости.
5. Подтвердите создание брони.

Цена услуги зависит от тарификации:

| Тип | Формула |
| --- | --- |
| `per_order` | цена × количество заказов |
| `per_day` | цена × количество × число ночей |
| `per_person` | цена × количество × число гостей |
| `per_unit` | цена × количество единиц |

Итог на странице пересчитывается JavaScript для удобства, но окончательная сумма
всегда вычисляется повторно на сервере по ценам из базы.

## Демонстрационная оплата

Из карточки брони откройте оплату. Sandbox предлагает два сценария:

- «Успешная оплата» создаёт платёж со статусом `paid` и подтверждает ожидающую бронь;
- «Симулировать отказ» создаёт платёж со статусом `failed` без подтверждения брони.

Реальные деньги и реквизиты банковской карты не используются. Форма существует
для демонстрации статусов и полного пользовательского пути.

## Личный кабинет

В `/account/` доступны:

- ближайшие и прошлые поездки;
- статус, даты, размещение и стоимость каждой брони;
- оплаченная сумма и остаток;
- заказанные услуги;
- счёт для печати;
- профиль и предпочтения;
- отзыв по завершённому проживанию.

## Дозаказ услуг

Услуга добавляется только к собственной активной брони. После заказа она получает
статус `new`, появляется в очереди сотрудников, а итог брони пересчитывается.
Оплатить новый остаток можно тем же sandbox-сценарием.

## Отмена брони

Гость может отменить собственную будущую бронь в статусе `pending` или `confirmed`.
Связанный успешный sandbox-платёж меняется на `refunded`. Для уже начавшегося или
завершённого проживания самостоятельная отмена недоступна.

## Восстановление доступа

1. Откройте `/forgot-password.php` и укажите email.
2. В демонстрационном режиме ссылка восстановления показывается в интерфейсе.
3. Задайте новый пароль до истечения 30 минут.

Токен хранится в базе только как SHA-256 и после использования становится
недействительным. В production ссылку должен доставлять настроенный почтовый
провайдер, а не веб-страница.

## Выход

Используйте кнопку «Выйти» в шапке. Система очищает данные авторизации и меняет
идентификатор сессии.
